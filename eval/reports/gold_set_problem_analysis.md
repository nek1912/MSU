**Date:** 2026-08-28

## Specific Problems

### Case 1: "What are the byelaws for a cooperative society?"
- **Gold chunks:** Letter header, letter body, definitions
- **Actual relevant chunks:** 17 chunks contain "byelaw" keyword
- **Problem:** Letter header/body don't answer the question

### Case 2: "Voting rights in a cooperative society"
- **Gold chunks:** Same 3 as Case 1
- **Actual relevant chunks:** `ce6579bc` ("to attend, participate and vote"), `9a5a665f` ("voting right")
- **Problem:** Gold chunks don't discuss voting rights

### Case 3: "Quorum requirements for cooperative society meetings"
- **Gold chunks:** Same 3 as Case 1
- **Actual relevant chunks:** `ce6579bc`, `4e776d7e` (General Body Meeting)
- **Problem:** Gold chunks don't discuss quorum

### Cases 4-40: Same pattern
- All use the same 3 chunks regardless of topic

---

## Root Cause

The gold set appears to have been generated by:
1. Taking the first 3 chunks from each document
2. Assigning them to all questions for that domain
3. No semantic validation of whether chunks answer the questions

---

## Correct Next Step

**Manual semantic audit of all 40 cases:**

1. For each case, read the question
2. Find chunks that actually contain answer-bearing evidence
3. Verify the chunk content answers/supports the question
4. Replace incorrect gold chunks
5. Record reason for every change
6. Freeze corrected gold set
7. Rerun retrieval evaluation

**Do NOT use embedding similarity** to select chunks — that would make evaluation circular.
